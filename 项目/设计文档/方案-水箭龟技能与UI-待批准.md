## 一、统一原则（照抄喷射火焰那套，不改它本身）

喷射火焰之所以「正常」，是因为它只认一个方向源：

```
鼠标 → 选目标 → 模型朝目标转身 → 特效从嘴/炮口沿「模型正前方」喷出 → 伤害用同一个正前方判定
```

水炮现在的问题就是**方向源有两个**：视觉走 `modelForward`，锁敌走另一条 `focusDir`，两边打架 → 看起来斜着出去、还会乱转。

所以四个技能统一成：

| 环节 | 规则 |
|---|---|
| 方向 | 只有一个：`modelForward(entity)`（模型正前方） |
| 锁敌 | 只负责**转身**（FacingService 把模型转到目标方向），绝不直接改弹道 |
| 特效 | 出生点取挂点（水炮=背部两炮口 / 喷水=炮口 / 冲浪=脚下浪头），朝向=模型正前方 |
| 伤害 | 用与特效**完全相同**的射线/扇形/体素，同一 tick 结算 |
| 距离 | 见下表，特效长度与判定距离必须相等（差 ≤0.3 格） |

## 二、四技能规格表

| 槽 | 技能 | 距离 | 形状 | 伤害 | 命中规则 |
|---|---|---|---|---|---|
| Q | 加农水炮 | **12 格** | 双炮口平行双束（间距 0.16），束宽 0.45 | 14/发 | 每发命中一次；锁定目标优先，束流永远朝模型正前方 |
| W | 高速旋转 | **半径 2 格**（已改） | 自身圆形 | 2/10tick × 5 次 | 圈内每个目标每 10 tick 一次，不重复 |
| E | 冲浪术 | **冲刺 6 格**，浪宽 3 格 | 直线 + 终点扇形 120° | 撞击 12 + 终点 8 | 路径上每目标最多 1 次；终点每目标最多 1 次 |
| R | 喷水（大招） | **前方 8 格 / 60°** | 六段扇形水柱 | 6~18 按距离分档 | 同一目标整招最多吃 2 档，不因多水柱重复结算 |

### 关键调整（相对现在）
1. **Q 水炮**：删掉「160° 手动转向」这个参数（它在跟模型转身抢方向盘），改成：有锁定目标 → 模型快速转向目标（`CHANNEL` 优先级 90°/tick）；没目标 → 朝鼠标方向。束流永远从炮口沿正前方出，**永不背身**（这点现在是好的，保留）。
2. **W 旋转**：攻击半径 4→2 格（已改），移速 0.6→0.34 格/tick（已改），特效加强（见三）。
3. **E 冲浪**：保持已实现的六阶段，只把终点扇形从 90° 改 120°、终点伤害独立结算。
4. **R 喷水**：按 `水箭龟.txt` 六阶段：蓄力 0.6s 原地 + 前方 60° 扇形预警（延伸到 8 格）→ 地下水纹传导 0.2s → 近/中/远三段水柱 → 消散 0.4s。**预警扇形与最终判定必须同一组参数**。

## 三、特效方案（都复用现有粒子/体渲染，不新增资源）

### Q 加农水炮
- 蓄力 0.4s：两个炮口各一团收缩水球 + 细水流回吸。
- 喷发：`WaterEffects` 的束流（已有），起点 `MouthAnchor.cannonPosition(left/right)`，末端加雾状溅射。
- 命中：命中点水花 + 白沫环。

### W 高速旋转（新增）
- 脚下：半透明水涡环（两层反向旋转，半径 1.2/1.8），随旋转相位转。
- 外圈：每 2 tick 向外抛 4 颗水滴（已加）。
- 结束时：一圈水爆 + 短暂水纹残留 0.5s。

### E 冲浪术
- 已按六阶段实现：蓄水 → 浪头 → 冲刺（浪体跟随、尾部拖水）→ 路径水花 → 终点扇形 → 消散。

### R 喷水
- 已按六阶段实现；只补「远端预警光环」与「分档亮度」，让 8 格的最远端看得见。

## 四、房间 UI 修复方案（图三糊的问题）

**病因**：`renderBackground` 调了原版 1.21 的菜单背景模糊，加上非整数缩放，整块都发虚。

**修法**（已按此改完代码，待你确认风格）：
1. 不调 `renderBackground`，全屏铺 `0xC0101214` 纯暗底 + 面板实色 `0xFFF2E2C2`。
2. 所有文字 `shadow = false`，字号只用原版整数缩放。
3. 列表行改成你要的样子：
   `房间一` + **居中两个头像**（红方左、蓝方右，空位是空槽）+ 右侧状态（`等待玩家加入` / `已满` / `倒计时 5s` / `对战中`）。
4. 按钮：`开始对战` / `退出房间` / `关闭`（不在房间时隐藏前两个里的「开始/退出」）。
5. 删掉行内 `#1`、`房主：xxx`、`1/2` 这些挤在一起的字。
