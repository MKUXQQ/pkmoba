## 0. 一句话

做一个 Fabric 模组：按 F12 切上帝视角，右键点地面，一只喷火龙走过来，模型动作用的是 Cobblemon 自带的。

**这是唯一目标。多做一个功能都是浪费。**

## 3. 功能范围（就这五条）

### F1 · 召唤
玩家执行 `/mo summon`，在玩家当前位置生成一只喷火龙。
- 生成成功给出提示；失败（比如已存在一只）也要有提示。
- 同一时间**只允许存在一只**由本模组控制的喷火龙。

### F2 · 上帝视角
按 **F12** 开关（按键要能在控制设置里重绑；另提供 `/mo god` 作为备用开关，防止 F12 被系统占用）。

打开时：
- 镜头脱离玩家身体，从玩家头顶上方向外移开；
- 镜头可移动：**WASD 平移**、**鼠标按住拖拽平移**、**鼠标推到窗口边缘平移**、**滚轮缩放**；
- 镜头活动半径**上限 32 格**，超出平滑回中；
- **玩家本体被锁定**：不能移动、不能挖掘、不能放置、不能交互、不能攻击；
- 玩家**仍可被攻击**（不是无敌）。

关闭时：镜头回到玩家身上，所有操作权限恢复。

### F3 · 点地移动
上帝视角下，**右键点击地面**，喷火龙走到那个点。
- 直线走过去，**不做绕障寻路**，撞墙就卡住（可接受，M0.5 不解决）。
- 移动速度 **5 格/秒**。
- 到达目标点 0.5 格内停下。
- 移动中新点一次地面，改为走向新目标点。
- 没有喷火龙时右键不发指令、不报错。

### F4 · 表现
- 模型、贴图、动作**全部用 Cobblemon 自带的**，不复制任何资源文件。
- 站着有 idle 动作，走动有走路动作（如果喷火龙的走路 pose 名不是通用的 `walk`，按实际模型里的名字用）。

### F5 · 清理
`/mo remove` 移除当前喷火龙。

### 明确不做（做了算超范围）
UI 面板、技能、血量条、CD、技能点、胜负、调试道具、训练木桩、多人同步优化、绕障寻路、强制区块加载、穿墙。

## 4. 技术路线（已定案，不要重新讨论）

| 项 | 决定 |
| --- | --- |
| 形态 | 独立附属模组，**不改** Cobblemon 本体源码 |
| 依赖 | Cobblemon 1.8.2 作为依赖，代码里直接调它的 API |
| 生成 | `Pokemon.sendOut(ServerLevel, Vec3, illusion, mutation)`；species = `cobblemon:charizard` |
| 实体类型 | 用 Cobblemon 的 `POKEMON` 类型，**不要**新注册实体类型 |
| 渲染 | **不要**注册 renderer——Cobblemon 客户端已全局注册 `PokemonRenderer`，它按 species 分发 |
| 控制方式 | `isNoAi = true` + 服务端每 tick 直接推 `setDeltaMovement` + **必须调 `move()`**（否则走路动画不播）+ 同步设 `yRot/yBodyRot/yHeadRot` + `hurtMarked`。不用 navigation、不用自定义 Goal |
| 归属 | **不进玩家队伍**，只设 `entity.ownerUUID` |
| 镜头 | `@WrapOperation` 打 `Camera.setup` 里的 `setPosition(DDD)`，**只改位置、不碰 `setRotation`**，朝向继续跟玩家视角走 |
| 区块 | **不做**强制加载（32 格在玩家加载半径内，够用） |
| 右键 | mixin `MouseHandler.onPress` 的 HEAD 处 cancel，上帝视角下把右键从"使用物品"改成"发移动指令" |
| 网络 | Fabric 原生 `CustomPacketPayload` + `PayloadTypeRegistry.playC2S` + `ServerPlayNetworking` |
| 锁玩家 | 以**服务端**为准：每 tick 清零水平速度并回写 x/z（保留 y）+ `hurtMarked`；客户端清输入只作辅助 |
| 权威 | 服务端自己维护"谁在上帝视角"，**不信客户端上报的状态** |

## 5. 硬性要求

1. `gradlew build` 必须通过，产出 jar。
2. **必须做服务端冒烟测试**：起一个 headless 的 Fabric 1.21.1 dedicated server，装 Cobblemon + 本模组，验证：
   - 服务端能起来，无崩溃；
   - `/mo summon` 注册成功；
   - 服务端能生成喷火龙实体（日志能看到实体存在）。
3. **mixin 目标必须核对**：`Camera.setup`、`MouseHandler.onPress` 在 1.21.1 映射里的**真实签名**要核实（javap 或 mappings 文件），签名错一个就是启动崩溃。
4. **不复制 Cobblemon 的任何资源文件**。
5. 注释用中文，关键决策处写清"为什么这么做"。
6. **不许虚报**：没验证的写"未验证"，失败就贴失败输出。

## 7. 已知未证实点（必须正面回应，不许含糊）

| # | 未证实 | 怎么处理 |
| --- | --- | --- |
| 1 | 喷火龙的模型类（`CharizardModel`）在源码里没找到，走路 pose 名不确定 | 去 resources 里的 poser/animation json 里确认实际 pose 名，按真实名字写 |
