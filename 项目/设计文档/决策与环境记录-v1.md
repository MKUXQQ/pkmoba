## 一、项目背景

在《我的世界》(MC 1.21.1) 里做**上帝视角 MOBA 式对战模组**：玩家本体不能动，镜头脱离身体，操控一只宝可梦用 QWER 打实时战斗。首期只做喷火龙。

工程来源：`F:\deepseek\项目\宝可梦工程文件\cobblemon-1.8.2`（Cobblemon 1.8.2 完整源码，含 fabric / neoforge / common 三模块）。

---

## 二、需求里最初查出的 8 个问题

拿到需求后先做的不是写代码，是找漏洞。以下 8 条是原始需求里**自相矛盾、没有定义、或与目标冲突**的地方。

| # | 问题 | 后果 | 最终处理 |
| --- | --- | --- | --- |
| 1 | "MOBA"没有队伍、基地、兵线、经济、胜负 | 说好的 MOBA 只是"上帝视角动作对战" | 降级为**沙盒对战** |
| 2 | 没说改本体还是做附属模组 | 决定未来维护成本 | 做**独立附属模组** |
| 3 | 移速 100 = 1 格/秒，比史蒂夫走路慢 4 倍 | 手感是乌龟 | 改为 **5 格/秒** |
| 4 | E 说"飞行中放技能不打断"，R 说"蓄力中不能动" | 两技能同时按下时规则冲突 | **R 可打断飞行** |
| 5 | 表格"总伤害"语义不明（单体？分摊？） | 群伤技能数值全乱 | **单目标满命中，各目标独立** |
| 6 | Q 没有射程 | 主力技能没法定位 | 定 **8 格** |
| 7 | "等待重置后重新召唤"没给时间 | 玩家立刻能感知的数值缺失 | 改为**一命制**（详见 B5） |
| 8 | 调试项有"吸力大小"，但需求里没有吸力 | 调一个不存在的机制 | **删除** |

## 三、决策台账

每组格式：**编号 · 问题 → 选项 → 定案 → 理由**

### A 组：不决定就不能开工

**A1 · 玩法骨架**
- 选项：A 沙盒对战（无兵线/基地/经济）/ B 半 MOBA（加据点、胜负条件）/ C 完整 MOBA（基地塔兵线经济装备）
- **定案：A 沙盒对战**
- 理由：C 的工作量是 A 的 5 倍以上，而在"上帝视角操控宝可梦"这个核心手感没被验证之前，堆 MOBA 骨架等于赌博。先把打架做爽。

**A2 · 代码形态**
- 选项：A 独立附属模组 / B 直接改 Cobblemon 本体 / C 混合
- **定案：A 独立附属模组**
- 理由：Cobblemon 升级不用重做，能和服务器上的原版 Cobblemon 共存，也不用分发修改版。喷火龙的模型/贴图/动作可以直接按其命名空间引用，不用复制资源。

**A3 · 加载器**
- 选项：A 只做 Fabric / B 只做 NeoForge / C 双端同做
- **定案：A 只做 Fabric**
- 理由：迭代最快。C 会多 30~40% 工作量，且要维护两套 mixin。

**A4 · 联机形态**
- 选项：A 单机优先 / B 直接做联机
- **定案：A 单机优先**
- 理由：先跑通玩法。但**技能判定全部写在服务端**，客户端只做表现——这样以后开联机不用重写。

### B 组：核心手感

**B1 · 移速换算**
- 选项：A 100=1 格/秒 / B 100=5 格/秒 / C 100=4.3 格/秒
- **定案：B 5 格/秒**
- 理由：对齐 MOBA 手感。A 的数值下，喷火龙走完 6 格射程要 6 秒，没法玩。

**B2 · E 飞行与 R 蓄力的冲突**
- 选项：A 互斥 / B R 可打断飞行 / C E 可打断蓄力
- **定案：B R 可打断飞行**
- 理由：给了空中接大招的操作空间，比互斥更好玩。
- **连带后果**：必须定义打断后的物理表现（见 D3）——空中蓄力、放完继续下落。

**B3 · "总伤害"的含义**
- 选项：A 单目标满命中 / B 伤害池平分 / C 单体满伤 + 多目标递减
- **定案：A 单目标满命中，每目标独立，不分摊不递减**
- 理由：唯一能同时满足"群伤"和"90 这个数"的解释。B 会让打 3 个目标每人只剩 30，技能表全部失真。

**B4 · Q 的射程与重复命中**
- 选项：A 8 格 + 可重复命中 / B 6 格 + 可重复 / C 10 格 + 每 3 秒最多 2 次
- **定案：A 射程 8 格，可重复命中，满伤 90**
- 理由：Q 是主力输出，必须让"18×5=90"能完整兑现。

**B5 · 死亡后多久能重新召唤**
- 选项：A 20 秒 / B 10 秒 / C 30 秒 / D 递增
- **定案：改为胜负规则——一方宝可梦全部阵亡，对方获胜**
- 说明：这不是选项之一，是需求方的重新定义。
- **产生的矛盾**：单机没有"对方"；且只有一只喷火龙时，"全部阵亡"等于死一次即负。
- **连带处理**：见 D1（对手是谁）、D2（一命制还是复活制）。

**B6 · 调试项"吸力大小"**
- 选项：A 删除 / B 改成"减速强度" / C 保留并给 W 加真实拉扯
- **定案：A 删除**
- 理由：需求里根本没有吸力机制，W 明确写了"不拉扯位移"。C 属于改玩法，不是改参数。

### C 组：细节默认（未提异议，按默认锁定）

| 编号 | 问题 | 默认值 |
| --- | --- | --- |
| C1 | 上帝视角下玩家本体能否被攻击 | 能（否则等于无敌挂机） |
| C2 | 镜头能推多远、地形怎么办 | 上限内自由，超出平滑回中；镜头中心强制加载区块（半径后修正为 32 格，见 D6） |
| C3 | W 的减速对友方生效吗 | 生效（减速不算伤害） |
| C4 | R 是瞬发还是弹道 | 瞬发落点 + 爆炸 |
| C5 | R 被什么打断 | 蓄力中受任何非己方来源伤害即打断 |
| C6 | 种族值是否接入 | 不接入，仅作后续平衡参考 |
| C7 | F12 能否重绑 | 开启与退出都可重绑，默认 F12 |
| C8 | 要不要训练木桩 | 要：9999 血、不还手、飘伤害数字 |

### D 组：由前面选择连带产生的新问题

**D1 · 首版的"对手"是谁**（B5 与 A4 的直接冲突）
- 选项：A 单人 + 木桩 / B 单人 + AI 敌方宝可梦 / C 局域网 1v1
- **定案：A 单人 + 训练木桩**
- 理由：先把操作和技能调爽。胜负逻辑照写，但 v1 触发不了。

**D2 · 一只宝可梦时的胜负模型**
- 选项：A 一命制（死一次结束）/ B 复活制 + 另设胜负条件 / C 复活制 + 递增
- **定案：A 一命制**
- 理由：与"全部阵亡即负"最自洽。

**D3 · R 打断飞行后的物理表现**
- 选项：A 空中悬停蓄力、放完受重力下落 / B 立即落地再蓄力 / C 就地瞬发不蓄力
- **定案：A 空中悬停蓄力**
- 理由：好看、实现简单。B 会有 1~2 秒落地延迟；C 等于白嫖大招。

**D4 · E 的位移收益**（B1 改 5 格/秒 后的连带问题）
- 算式：自己跑 15 格 = 3.0 秒；E 飞 15 格按原设定的 5.6 格/秒 = 2.7 秒。只快 0.3 秒还要吃 2 秒 CD。
- 选项：A 提到 12 格/秒 / B 提到 8 格/秒 / C 不动
- **定案：A 12 格/秒**（15 格约 1.25 秒飞完）

**D5 · R 射程比 Q 还短**（B4 定 8 格后的连带问题）
- 选项：A R 提到 10 格 / B 提到 8 格 / C 保持 6 格
- **定案：A 10 格**

**D6 · 镜头范围过大**（C2 的默认值在 5 格/秒移速下不合理）
- 选项：A 上限 32 格 / B 上限 24 格 / C 维持 64 格
- **定案：A 32 格 + 超出平滑回中**

## 四、我补的默认值（需求未覆盖，已写入任务书）

1. 退出上帝视角后，喷火龙**留在原地静止待命**，不消失。
2. 上帝视角下 **Q 引导期间允许移动**（R 才是不能动的那个）。
3. 玩家本体死亡时，喷火龙消失，选择按钮复位。
4. 召唤点与方块/实体重叠时，向上或向旁找最近空位。
5. 召唤时技能点 = 10（满），CD 全清零。
6. Q 引导中的转向角速度上限 **90°/秒**，平滑跟随，不允许瞬间甩头。

### 5.2 喷火龙资源（已核查，全部存在）

### 5.5 排障记录：工作区权限报错

- **现象**：`Error: SetNamedSecurityInfoW failed (Win32 5): grantWrite(F:\deepseek\项目)`——命令根本没执行就退出。
- **原因**：沙箱处于 workspace-write 模式时要给工作区授权（写 DACL），而 `F:\deepseek\项目` 建在 `F:\deepseek`（DSH 安装目录）里，权限继承受限，授权失败。
- **后续**：会话文件策略切到 `danger-full-access` 后，沙箱不再做授权动作，命令恢复正常。
- **遗留风险**：`F:\deepseek\项目` 位于安装目录内，**重装或卸载 Harness 时可能连项目一起删除**。决定：继续用它，但等有实物产出后再做一份异地备份。

### 5.6 已发现的其他事实

- `宝可梦工程文件/cobblemon-1.8.2.zip`（112 MB）与已解压目录重复，可删。
- 工程目录里有 `.idea`、`.gitlab`、`archive`、`docs` 等，属原项目自带，不要动。
