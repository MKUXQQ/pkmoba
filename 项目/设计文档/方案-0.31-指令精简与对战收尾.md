# 方案 0.31：指令精简、X 召唤、C 换人、对战收尾（v2）

> v2 变更（依据 m06716）：头像确认用 PokeAPI 官方图裁头；**废弃独立的"我的宝可梦"浮卡，改为把队伍模块嵌进技能栏面板左侧**；换人键由 G 改为 **C**（切换下一只）；并按"优化设计"补充了若干细节。

## 1. 技能栏一体化改造（核心变化）

### 1.1 新面板布局（宽 254 → 306）

```
┌──────┬──────────────────────────────────────────────────────────────┐
│      │                       喷火龙                                  │ ← 名字在本体上方
│ 头像 │  ████████████████████████░░░░  100/100                       │
│ 40×40│  ┌────┐ ┌────┐ ┌────┐ ┌────┐                                 │
│      │  │ Q  │ │ W  │ │ E  │ │ R  │                                 │
│ ●●○  │  └────┘ └────┘ └────┘ └────┘                                 │
│ C 换 │         ▮▮▮▮▮▮▮▮▮▮  10/10                                     │
└──────┴──────────────────────────────────────────────────────────────┘
```

- 面板总宽 `306`，高仍 `98`，底部居中、`MARGIN=8`。
- **左侧队伍模块（宽 46）**：
  - `40×40` 当前宝可梦头像（Q 版网络图，等比缩放，深棕描边），位置 `x+5, y+14`；
  - 头像下方一排**队伍圆点**：`y+60`，每个 6×6，最多 6 个；实心=可用、空心=已阵亡、金色描边=当前上场；
  - 圆点下方 `C 换` 小字（`y+70`，MUTED 色），提示换人键。
  - 未召唤时头像整体压暗（`0x66FFFFFF` 叠层）+ 头像中央画一个 `X` 提示。
- 右侧现有内容整体右移 `52`：血条 `x+57 .. x+PANEL_W-9`，四个技能格从 `x+57` 起（`i*59`），豆珠区在右侧区域内居中。
- 面板左侧加一条 1px 竖分隔线（`x+50`，BORDER 色），视觉上和技能区分开。

### 1.2 换人倒计时（对局中）

- 有换人等待时，`C 换` 位置替换为红字 `12s`（`0xFFC94F3D`），每秒跳一次；
- 头像外框变红闪烁（每 10 tick 亮/暗一次）；
- 倒计时结束时该方判负（由服务端权威判定，客户端只显示）。

### 1.3 为什么嵌进技能栏而不是独立浮卡

- 用户图二想要的是"随时能看到我选的是谁"；技能栏本来就已经显示当前宝可梦名字与血量，再放一个浮卡会重复信息、挤占屏幕；
- 嵌进面板后：**一个面板 = 我是谁 + 我还剩几只 + 我怎么换 + 我能放什么**，视线不用跳；
- 屏幕左上恢复干净，只在右上保留对手条。

## 2. 键位最终表

| 键 | 功能 | 作用域 |
|---|---|---|
| Z | 开/关上帝视角 | 全局 |
| 空格 | 按住锁定镜头 | 上帝视角中 |
| Q/W/E/R | 四个技能 | 上帝视角中 |
| **X** | **召唤当前宝可梦到准星地面点（≤32 格）** | 上帝视角中（对局内=换人上场） |
| **C** | **切换到下一只宝可梦（循环，跳过已阵亡）** | 上帝视角中 |
| 左键 | 普攻/选目标 | 上帝视角中 |

- C 键默认绑定 `GLFW_KEY_C`；原 G 键解绑（`key.pkmoba.switch_pokemon` 的默认值改为 C）。
- C 只在"当前没有在场实体"或"想换下一只"时生效：服务端校验 `!busy` 且 `队伍里存在其他可用宝可梦`。
- C 的行为定义：**切换到下一只可用宝可梦并把当前这只撤回**（如果当前这只还在场，先撤下再放新的；不消耗、不记为阵亡）。

## 3. 队伍模型（修"打死不结束"）

```
PlayerProfile
  team: List<String>      // 拥有列表，初始只有选的 1 只
  fainted: Set<String>    // 已阵亡
  activeIndex: int        // 当前上场
```

| 操作 | 行为 |
|---|---|
| 开局选择 | `team = [selected]`（不再自动塞满所有种族） |
| `/mo pokemon add <种>` | 队伍追加；已有则提示 |
| 添加宝可梦道具 | 同上，走 ADD 模式选择界面 |
| C 换人 | `activeIndex` 循环到下一只未阵亡的 |
| X 召唤 | 生成 `activeIndex` 那只 |
| 阵亡 | 记入 `fainted`；若 `hasUsableLeft()` 为假 → 立即判负 |

判负仍为"队伍打光"，符合用户要求；20 秒不换自动判负作为补充。

## 4. 对战流程（含 20 秒倒计时）

```
开始 → 双方各 1 只在场
  │
  ├─ A 的宝可梦阵亡
  │    ├─ 播战败动画 45 tick（不立即移除）
  │    ├─ A.fainted += 该只；若 A 无可用 → 立刻 B 胜
  │    └─ 否则 A 进入 400 tick（20s）等待
  │           ├─ A 按 C → 切下一只；按 X → 在该点召唤
  │           └─ 20s 到 → B 胜（原因：换人超时）
  │
  └─ 任一方胜 → 弹"你获胜了！"横幅 + 双方聊天播报
```

## 5. 战败动画

- 服务端：HP 归零后 `dyingEntityId` + `dyingTicks=45`，广播 `FaintPayload(entityId, 45)`；45 tick 后 `discard()`；
- 客户端：水箭龟用 Cobblemon 原生 `faint`；喷火龙用自制 `animation.pkmoba_faint`（前倾下沉 → 侧倒 + 闪烁）；
- 期间该实体从 `BasicAttack.validTarget` 排除（`getHealth() <= 0`）。

## 6. 胜利播报

`MatchResultPayload(winnerName, youWin, reason)` → 屏幕正中米黄横幅（高 56、深棕 3px 描边），主文案 `你获胜了！` / `XX 获胜`，副标题为原因（`对手宝可梦全部阵亡` / `换人超时` / `管理员强制结束`），4 秒后 0.8 秒淡出；聊天栏同步。

## 9. Q 版头像（网络图，构建期入库）

- 源：`https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/other/official-artwork/<dex>.png`（实测 200，透明底 475×475）；
- `tools/fetch_pokemon_portraits.py`：下载 → alpha 包围盒 → 取上方 62% 裁方 → 缩到 **64×64**（LANCZOS）→ 4px 深棕外描边 + 2px 米色内描边 → 输出 `assets/pkmoba/textures/gui/pokemon/<name>.png`；
- 加种族只需在脚本 `DEX = [("charizard", 6), ("blastoise", 9)]` 加一行重跑；
- `SOURCE.md` 记录来源与版权（形象版权 Nintendo/Creatures/GAME FREAK，仅本地个人模组使用）。

## 10. 新增 payload 与服务端下发

| Payload | 方向 | 字段 |
|---|---|---|
| `SummonPayload` | C2S | `double x, y, z` |
| `SwitchPayload` | C2S | 已有 `SwitchPokemonPayload`（空记录），复用 |
| `FaintPayload` | S2C | `int entityId, int ticks` |
| `MatchResultPayload` | S2C | `String winnerName, boolean youWin, String reason` |
| `TeamStatePayload` | S2C | `List<String> team, List<String> fainted, String active, boolean summoned, int pendingTicks` |

`TeamStatePayload` 在以下时机下发：进服、选择/添加宝可梦、召唤、换人、阵亡、复活、对局开始/结束。客户端据此渲染头像、圆点、倒计时。

## 11. 设计优化项（我主动补的，均可回退）

1. **面板宽度自适应**：队伍只有 1 只时不显示圆点行，省一行空间。
2. **换人保护**：C 键在"当前宝可梦正在放 R/E"时忽略（避免打断自己的引导技能），提示"技能中无法换人"。
3. **召唤落点防卡**：`groundPos` 找不到安全落点时抬高 1 格重试，再失败则在玩家脚边生成。
4. **召唤距离反馈**：超过 32 格时准星处显示红框 0.5 秒，而不是只发聊天。
5. **阵亡提示分级**：自己宝可梦阵亡 → 面板圆点变空心 + 中央红字 `按 C 换人`；对手阵亡 → 右上条短暂显示 `击倒！`。
6. **对局结束清理**：`end()` 时确保 `TeamStatePayload` 复位、`GodView` 关闭、实体延迟动画播完再 discard。
7. **`/mo duel stop` 二次确认**：`stop all` 需要 `stop all confirm`，防止误踢全部对局。
8. **头像缓存**：客户端首次用某头像时 `TextureManager` 预加载，避免首帧白块。

2. 单人：首进选择界面 → 选喷火龙 → 技能栏左侧出现头像与 1 个金边圆点 → 按 X 在准星地面召唤 → `/mo pokemon add 水箭龟` → 圆点变 2 个 → 按 C 切到水箭龟（面板变色、技能图标变水箭龟套）；
