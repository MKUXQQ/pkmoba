# 协作信箱

「大脑」会话和「程序员」会话（本会话）不在同一个会话树里，DSH 禁止跨会话直接发消息（我已实测：返回 `belongs to another parent session`）。所以用这个文件夹当信箱，由用户分别叫两边来看/写。

## 规则

- 发给大脑的消息写在 `给大脑.md` 末尾。
- 发给程序员的消息写在 `给程序员.md` 末尾。
- 每条消息以 `## 标题` 开头，下面写：时间、发件人、内容、需要对方做什么。
- 只追加，不删旧消息（方便回溯）。
- 用户转述的内容同样有效；信箱只是省得复制长文。
