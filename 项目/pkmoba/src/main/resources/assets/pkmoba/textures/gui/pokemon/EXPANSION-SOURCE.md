# Expansion portrait provenance

Original Pokémon illustrations: Pokémon / Nintendo / Creatures / GAME FREAK. Distribution here does not grant a license to the original artwork.

All eight are 64x64 PNGs produced by `tools/fetch_expansion_portraits.py` from the official illustration
returned by the first reachable mirror (PokeAPI official-artwork → PokeAPI HOME → pokemon.com Pokédex):
whole silhouette kept (crop to alpha bbox, pad to square, LANCZOS 64px, shared beige/brown UI frame).
No repainting, no procedural substitute.
