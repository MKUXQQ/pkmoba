# PKMOBA 0.49.0 验收清单

本次范围：固定 1v1、预瞄与施法锁向、房间规则与本场阵容。不是 2v2/3v3、观战或候战系统。

## 两客户端游戏验收（需人工运行）

### 房间与权限

1. 用已有完整竞技场进入 H 大厅，空房无旧成员占位，首个加入者成为房主。
2. 房主在右下「房间设置」修改名称，设置每人最多 3 只，普通成员只能「查看规则」。
3. 公开房直接加入；设置密码后，大厅仅显示锁图标，输错密码不能入房，正确密码可以加入。普通成员不能更改密码/规则。
4. 两人准备后修改关键规则，双方准备状态清除并收到变更摘要；修改自己的阵容仅取消自己的准备。
5. 倒计时期间不能静默改规则、改阵容或通过旧选择/命令入口更换收藏；先取消倒计时才能编辑。战斗中规则锁定。
6. 重启世界/服务器，房间名称、密码与携带限制保留；比赛、房主、成员、准备和倒计时不恢复。
7. 非管理员不能通过 `/mo arena create/delete` 修改场地；玩家仍可 `/mo arena list`。战斗中不能借 `/mo revive`、旧选择包或添加/删除收藏命令改变参赛队伍。
8. 房内或人机对局中的玩家不能接受旧挑战进入第二场比赛；密码错误重试不能高频触发昂贵哈希。

### 获取与本场阵容

1. 左下「选择宝可梦」可获取原白名单宝可梦、查看收藏、加入/移出本场。
2. 移出本场后仍在收藏中，能够重新加入；不触发永久删除。
3. 调整本场顺序，把末位设为首发，保存返回同一房间；两端显示一致。
4. 默认最多 3 只，空阵容、超过上限、重复和未拥有物种都不能准备或开战（服务端校验）。
5. 对战只允许选择本场成员，不可通过 C/X/旧界面召唤收藏中未报名的成员；阵亡判断只计算本场成员。
6. 开局恢复血量、技能点、冷却和可出战状态；结束后收藏完整，没有永久变成赛事子集。

### 朝向与施法

对喷火龙、水箭龟、妙蛙花和皮卡丘逐一测试 Q/W/E/R：

1. 无施法时转动鼠标，头身体一起平滑预瞄；边走边瞄时旧移动命令不能拉走朝向。
2. 确认后立刻将鼠标移到背面：直线/扇形保持确认方向；落点技能保持确认坐标；位移保持确认路径；自身范围仍以自身为中心。
3. 起手、持续与收招期间，范围表现、模型朝向和伤害一致，不能跟随后续鼠标甩动。
4. 嘴和炮口定位器可以随技能骨骼动作移动，但不能改写已确认的逻辑攻击方向。
5. 技能结束平滑恢复当前鼠标预瞄；取消、倒下、撤回、换宠、结束比赛后不残留锁向。
6. 两端观察同一技能方向一致；墙体、距离与竞技场合法落点限制仍生效。
7. 喷火龙既有屏幕表现保留，不因本次房间/朝向修改被删除。

构建和自动回归结果由交付报告另行记录。以上是实际游戏验收步骤，不代表已经启动客户端或完成双端实测。
