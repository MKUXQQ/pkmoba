# 本轮技能重制方案（制作中）

## 目标
- 排除喷火龙、妙蛙花、水箭龟现有美术；更新皮卡丘和8只扩展物种。
- 能量和自然物使用有体积、带UV贴图的闭合网格，不再用两张交叉透明光片冒充模型。
- 拳、脚、爪攻击以宝可梦本体接敌动作承担主画面，命中特效只负责短促接触反馈。

## 视觉方向
| 物种 | 视觉语言 | 近身原则 |
| --- | --- | --- |
| 皮卡丘 | 金白色六棱实体闪电、贴图能量球、弯曲编织电网 | 电光一闪保留本体冲撞，去除巨大残影光片 |
| 路卡利欧 | 蓝白波导球、短暂接触反馈 | 拳击、突进拳、近身战由本体手臂动作执行 |
| 暴雪王 | 有棱角冰晶、结霜冰墙、稀疏分层暴雪 | 不用巨大整屏冰贴图遮住敌我模型 |
| 火焰鸡 | 紧贴拳脚的小型火焰网格 | 冲拳与二连踢实际接敌，火焰不替代拳脚 |
| 耿鬼 | 紫色封闭暗影球与毒液球、有限浮动符号 | 突袭以本体接近攻击 |
| 班基拉斯 | 带裂纹岩石、尖锥石柱、低密度砂砾 | 咬击依本体头部动作与接触 |
| 烈咬陆鲨 | 深蓝龙能量和局部沙土网格 | 爪击、冲撞以本体骨骼动作和位移表现 |
| 巨钳螳螂 | 金属反光与短促切击 | 拳钳攻击本体接敌，不发射巨大拳头光片 |
| 沙奈朵 | 低饱和粉青精神球、薄环与预知未来晶核 | 保持远程施法辨识，不堆满同心圆 |

## 控制与召唤
- 技能确认时锁定终点；一般施法过程中允许移动，不因新鼠标位置偷偷改变最终落点。
- 本体突进/接敌短阶段保留技能自身位移优先级，不能同时被普通路径撕扯。
- C以旧出战实体世界位置作为换宠锚点，不退回玩家位置。
- X以服务器计算的投球抛物线和碰撞终点召唤，客户端显示相同轨迹。
- 头顶血条分离层深、明确填充和轮廓，视觉锚点匹配缩放后的模型。

此文为制作方案，不是实机画面或完成证明。最终测试结果另行记录。
