# PKMOBA 0.22.0 修复说明

## 本轮改动
- 服务端 `/mo summon charizard`（或 `/mo summon`）仍进入右键选点召唤；客户端镜头命令独立为 `/mocamera`，不再占用 `/mo` 根节点。生成失败会向玩家提示并保留日志。
- `/mocamera edge 8`、`/mocamera edge 5 5 5 12`、`/mocamera speed 18`、`/mocamera preview on|off`、`/mocamera reset`；旧 `/mo camera` 不再使用。
- 上帝视角隐藏原版准星，退出恢复。默认 Z 开关，已保存的旧绑定不会强制重置。
- 进入前保存位置、朝向、重力、无敌与飞行属性；在原位上方12格检查完整碰撞箱，无安全空间拒绝进入。悬停锁XYZ并清理速度与摔落距离。
- 正常退出/断线尝试返回原位置；原位置不安全搜索附近支撑点，再尝试出生点附近。极端无安全候选会告警并解除锁定。死亡、重生、换维度不拉回旧坐标。
- 服务器发送升空前镜头锚点，避免无受控宝可梦时镜头随本体升高12格；仍为默认自由镜头、按住空格跟随。
- 仅隐藏Cobblemon初始伙伴提示绘制，不改伙伴数据、存档及其他通知。
- 米黄色技能图标面板：统一原创像素图标，图标下方显示实际绑定键，再显示完整技能名称。消耗数字移到悬停提示；保留血条、豆条、冷却与蓄力提示。
- 面板仅在上帝视角、有存活受控喷火龙并收到技能状态时显示。没有实体/未适配物种不套用喷火龙技能；切换实体先清旧显示数据。

## 联网诊断
网页抓取成功，但搜索服务返回401无效凭据，不能通过换搜索词修复。需要用户在插件内置设置的Web search配置有效凭据及其对应服务地址；本轮未修改任何密钥或地址。四枚图标采用原创绘制，不宣称官方或网络素材。

## 验证边界
编译和remap、成品资源与哈希检查不等于客户端游戏验收。尚未实际启动客户端检查召唤、Mixin应用、悬停生命周期与视觉效果。构建没有现成单元测试（test NO-SOURCE）。0.22变更了god_state网络包，联机客户端与服务端需同时升级，不混用旧包。

## 游戏内回归清单
1. `/mo summon charizard` 补全/执行后右键选地生成；`/mo remove`后HUD消失；`/mocamera`设置独立工作。
2. 空地Z进入后人物悬停、准星隐藏；再Z回原处，恢复原属性；低顶/液体/高度上限拒绝不安全悬停。
3. 删除原位置地板后退出应找有支撑位置；断线重连、死亡重生、换维度不遗留锁定/异常传送。
4. 无龙进入镜头不抬高12格；默认自由、空格跟随、释放保留位置。
5. 初始伙伴提示不显示，其他提示正常，伙伴选择功能仍可用。
6. 四图正确、绑定键在下、完整名不挤、改键同步；不足豆压暗、CD遮罩、悬停消耗；HUD上不推屏。
