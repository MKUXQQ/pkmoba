# PKMOBA 0.49.0

## 本次实现

- 固定红蓝双方 1v1；不是多人队战、观战或候战系统。
- 房间左下选择宝可梦：获取已实装物种、查看收藏、编辑本场参赛子集、调整顺序和首发；移出本场不删除永久收藏。
- 房间右下分类设置：基础、对战规则、成员权限、高级；普通成员只读房间规则，房主可改名、设置/清除密码及修改携带上限。
- 每人默认最多 3 只，可设 1–6 只；空阵容、重复、未拥有或超出上限的阵容由服务端拒绝。
- 双方准备后由房主开始 10 秒倒计时；取消准备可恢复编辑。关键规则变更取消双方准备，自己的阵容变更取消本人准备。
- 房间名称、容量与盐化密码摘要保存到世界数据；成员、比赛、本场阵容和准备状态不跨重启恢复。不会向客户端广播密码摘要。
- 比赛使用独立临时玩家档案，换宠、召唤和胜负只计算本场名单；永久收藏不会被赛事名单覆盖。
- 喷火龙、水箭龟、妙蛙花、皮卡丘预瞄跟随；确认施法后按类型锁定方向/落点/位移路径，自身范围技能仍以自身为中心。按实体清理旧战斗状态，不清空其他房间对局。
- 移除无服务端确认的客户端预测转身，避免拒绝施法仍拉动本地模型；保留喷火龙原有屏幕表现。
- 对旧挑战、对局中收藏修改、管理员场地命令及密码重试补充校验。

## 使用

1. 客户端与服务器都安装同一版 0.49.0；本次房间网络协议有变化，不能混用旧版。
2. 按 H 打开大厅，加入房间；密码房按提示输入密码。
3. 左下「选择宝可梦」配置本场阵容，首位为首发；右下房间设置查看/编辑规则。
4. 双方准备，房主开始倒计时。进入场地后按 C 选成员、按 X 召唤，仍使用原 Q/W/E/R 技能操作。
