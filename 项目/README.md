# 项目工作区

这里存放我们合作开发的各个工程。一个工程一个独立文件夹，互不干扰。

## 协作约定

1. **一个工程一个文件夹**：文件夹名用小写英文或拼音，不带空格。
2. **每个工程必须有 README.md**：说明做什么、怎么运行、依赖什么、目录结构。
3. **能自测的必须有验证手段**：测试脚本或验收步骤，交付前自己先跑通。
4. **不把密钥、密码、个人隐私写进代码或提交记录**。
5. **优先零依赖方案**：要装依赖先说明理由和体积。
6. **先方案后动手**：需求确认、技术选型说清楚，再开始写。

## 协作流程

| 步骤 | 谁做 | 产出 |
| --- | --- | --- |
| 1. 需求 | 你 | 一句话说清：解决什么问题、给谁用、必须有什么 |
| 2. 方案 | 我 | 技术选型、取舍、页面/交互草案、工作量 |
| 3. 实现 | 我 | 能运行的代码，小步推进，关键节点汇报 |
| 4. 验收 | 你 | 试用；不满意直接说，我改 |
